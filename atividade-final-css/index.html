O que são Easter Eggs?

No mundo dos videogames, um easter egg é uma piada interna, uma imagem, mensagem ou recurso secreto escondido intencionalmente dentro de um jogo.

O primeiro easter egg famoso surgiu no jogo Adventure (1979) para Atari 2600, onde o criador Warren Robinett escondeu seu nome em uma sala secreta.
